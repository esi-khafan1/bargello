# BARGELLO IRAN — پلتفرم فروشگاهی عطر و ادکلن اورجینال بارگلو

پلتفرم جامع فروش آنلاین عطر و ادکلن اورجینال **بارگلو ترکیه (Bargello Perfume)** طراحی‌شده با زیبایی‌شناسی مینیمال و لوکس نسخه اروپایی (`bargelloperfume.ee`) و بومی‌سازی کامل فارسی (RTL)، واحد پولی **تومان**، موتور هوشمند کمپین **۱+۱ ادکلن**، پنل مدیریت اختصاصی و دیتابیس ابری **Supabase** (ریجن فرانکفورت `eu-central-1`).

## امکانات کلیدی

- **موتور دوگانه کمپین ۱+۱ (Buy 1 Get 1 Free)**:
  - انتخاب مستقیم ادکلن دوم رایگان در صفحه هر محصول مشمول و پک‌ساز صفحه اصلی.
  - محاسبه خودکار ۱۰۰٪ تخفیف روی هر جفت ادکلن در سبد خرید + هشدار هوشمند زمانی که تعداد فرد از ادکلن‌های جشنواره انتخاب شده باشد.
- **جستجوی هم‌زمان کد سه رقمی و برند جهانی**: پشتیبانی از ارقام فارسی و انگلیسی (`۵۶۱` / `561`، `۱۲۲`، `۷۰۹`)، نام برندهای جهانی (`Dior Sauvage`، `Baccarat Rouge`، `Creed Aventus`، `Chanel`) و نت‌های هرم بویایی.
- **معماری سرور-محور سازگار با اینترنت ایران**: کلیه ارتباطات دیتابیس از مسیر Route Handlerهای سرور Next.js (`/api/*`) عبور می‌کنند تا کاربران داخل ایران تنها با دامنه اصلی سایت ارتباط داشته باشند.
- **تسویه‌حساب و پیگیری سفارش**: ثبت کامل سفارش در دیتابیس با کد رهگیری یکتا (`BRG-XXXXXX`)، پرداخت کارت‌به‌کارت (با ثبت کد فیش)، هماهنگی واتساپ، و اندپوینت آماده درگاه زرین‌پال (`/api/payment/zarinpal/*`).
- **پیشخوان مدیریت (`/admin`)**: مدیریت سفارش‌ها و ثبت کد رهگیری پستی، افزودن/ویرایش/حذف محصولات و موجودی، و تنظیمات کمپین ۱+۱.

## راه‌اندازی و اجرا

1. کپی فایل تنظیمات محیطی:
   ```bash
   cp .env.example .env.local
   ```
2. نصب وابستگی‌ها و اجرای سرور توسعه:
   ```bash
   npm install
   npm run dev
   ```
3. اجرای تست‌ها و بیلد نهایی پروداکشن:
   ```bash
   npm test
   npm run typecheck
   npm run build
   ```
